Profile Designer

Sketch mode: tap to add points. Tap to add each corner. Press and drag any point to reshape it. For a hem, draw the return back alongside the previous leg—even very close to it. The larger invisible touch targets make tight hems easier to shape. Exact size comes from the dimension you enter after finishing. Tap Finish Sketch when done.

Shop-sketch workflow: sketch the shape first, then enter exact leg dimensions. Tap a leg to edit it. Bend labels are shown directly on the profile, and tight returns are identified as hems.

Nominal developed width
Nominal flat width currently adds the leg dimensions. Exact bend allowance/deduction depends on metal thickness, inside radius and brake/tooling setup; do not treat this as a production cut size until those rules are entered.
