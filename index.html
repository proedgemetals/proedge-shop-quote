Profile Designer

Sketch mode: tap to add points. Tap to add each corner. Press and drag any point to reshape it. For a hem, draw the return back alongside the previous leg—even very close to it. Shop-sketch workflow: sketch the shape first, then enter exact leg dimensions. Tap a leg to edit it. Bend labels are shown directly on the profile, and tight returns are identified as hems.
